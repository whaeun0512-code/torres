# Our days
커플의 기념일, 여행 지도, 일정, 사진을 기록하는 반응형 웹사이트입니다.

## 실행
Node.js 20.19+ 또는 22.12+에서:
```
npm ci --cache /tmp/torres-npm
npm run dev -- --port 3000
```
프로덕션 빌드: `npm run build`. 미리보기: `npm run preview`.

## 기능과 저장
- 시작일을 포함한 함께한 날짜 계산, 이름 및 시작일 설정
- 지도 클릭 또는 좌표로 여행 기록 저장 및 삭제
- 월별 달력, 일정 저장 및 삭제
- 사진 업로드(최대 변 1400px로 축소), 제목·날짜 수정 및 삭제
- 브라우저 localStorage에 저장. 계정, 기기 간 동기화, 서버 백업은 제공하지 않습니다. 브라우저 데이터 삭제 시 기록이 삭제됩니다.
- 온라인 지도 타일은 CARTO/OpenStreetMap을 이용합니다. 네트워크 차단 시 번들에 포함된 세계 지형과 도시 표기가 표시되며 위치 선택과 기록은 계속 사용할 수 있습니다.

기본 앨범 사진은 영감용 샘플이며 실제 저장된 사진 수에 포함되지 않습니다.
사진: StartBootstrap 예제 자산(Unsplash), 지형: johan/world.geo.json. 외부 글꼴 및 이미지 요청 없이 실행됩니다.
